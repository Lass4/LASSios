About LASSios

LASSios is a community-focused iOS package repository concept for tweaks, themes and tools. This starter website is designed for a clean mobile experience and can be hosted with GitHub Pages. The live package feed still needs to be generated and published.

How to Add LASSios

When your APT feed is live, add its URL to your package manager.

Replace YOUR-USERNAME with your GitHub username. The repository URL will not work as a package source until valid APT metadata and package indexes have been published.

⬡ For Sileo

  1. Open Sileo on your jailbroken iPhone.
  2. Go to Sources and tap Add (+).
  3. Enter your LASSios repository URL below.
  4. Tap Add and refresh your sources.
https://YOUR-USERNAME.github.io/LASSios/

▧ For Cydia

  1. Open Cydia on your jailbroken iPhone.
  2. Go to Sources → Edit → Add.
  3. Enter the same LASSios repository URL.
  4. Tap Add Source and wait for refresh.
https://YOUR-USERNAME.github.io/LASSios/
